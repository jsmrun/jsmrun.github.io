# Jersey Mae P. Delfinado — Personal Portfolio

Static portfolio website converted from `Delfinado_Portfolio.pdf` and ready for **GitHub Pages**.

## Included Files
- `index.html` — Main single-page portfolio with interactive project case-study modals
- `style.css` — Responsive warm-cream and terracotta stylesheet
- `script.js` — Project filtering, case-study modal navigation, mobile menu, and clipboard copy
- `assets/` — Extracted portrait photos, project screenshots, and certification images

## Deploying to GitHub Pages
1. Create a new public repository on GitHub (e.g., `portfolio` or `<your-username>.github.io`).
2. Extract all files from this ZIP archive and upload them to the root of the repository (`index.html`, `style.css`, `script.js`, and the `assets/` folder).
3. Go to **Settings > Pages** in your GitHub repository.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, and click **Save**.
5. Your site will go live at `https://<your-username>.github.io/<repo-name>/` within a minute or two.
